# Code of conduct

Be respectful and constructive. Assume good faith, critique work rather than
people, and keep discussion on topic.

Not acceptable: harassment, discrimination, personal attacks, publishing other
people's private information (including real message content), and spam.

Maintainers may edit, hide, or remove comments and contributions that break these
rules, and may block repeat offenders. Report a problem privately to the
maintainer through a GitHub private message or the contact on the maintainer's
profile.
